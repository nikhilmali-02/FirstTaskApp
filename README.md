# FirstTaskApp

This project is part of Task 1 of the Android App Development Internship at ApexPlanet Software Pvt. Ltd.

## Task Objective
- Complete onboarding and environment setup
- Set up Android Studio and required SDKs
- Learn Android project structure
- Create a basic Android app using XML layouts and Kotlin

## What This App Does
- Displays a simple user interface with a TextView and a Button
- Updates the text when the button is clicked
- Runs successfully on the Android Emulator

## Technologies Used
- Kotlin
- Android Studio
- XML Layouts
- Android SDK

## Learning Outcome
Through this task, I learned:
- How to set up an Android development environment
- Basic Android project structure
- Activity lifecycle basics
- Handling simple UI interactions

This repository represents the successful completion of Task 1.

## Task 2 - UI Implementation

In this task, I designed and implemented a Login Screen UI using XML layouts. 
The interface includes input fields for email and password along with a login button. 
Basic click handling is implemented using Kotlin.
